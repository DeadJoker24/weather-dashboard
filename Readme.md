# Weather Dashboard

A simple weather dashboard built with **HTML, CSS, and JavaScript** that allows users to search for any city and view its current weather information.

## Features

* Search weather by city name
* Displays current temperature
* Displays humidity
* Displays wind speed
* Shows weather condition
* Loading state while fetching data
* Error handling for invalid cities and API failures
* Reset button to clear the dashboard

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Open-Meteo API

## API

This project uses the [Open-Meteo API](https://open-meteo.com/) for:

* City geocoding
* Current weather data

No API key is required.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/DeadJoker24/weather-dashboard.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **VS Code Live Server** to run the project locally.
